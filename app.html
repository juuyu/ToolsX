欢迎使用 Docs

这里是 Tools-X 的内置笔记，支持 多级目录 与 Markdown 书写。

基本操作

  • 左侧目录树支持 拖拽 整理
  • 悬停文件夹行可新建子笔记 / 子文件夹
  • 编辑自动保存，右上角可切换 源码 / 预览

Markdown 支持

  1. 行内语法：加粗、斜体、删除线、行内代码
  2. 任务清单：
    • 多级目录
    • Markdown 渲染
    • 你的第一条笔记
  3. 代码块、表格、引用

提示：顶部搜索框可以直接搜笔记名称与内容。
